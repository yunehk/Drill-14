# Drill #14 — 새의 비행 애니메이션

`bird_animation.png`로 새 10마리가 날갯짓하며 좌우로 반복 비행합니다.
소년이 달리는 기존 1600×600 화면 위쪽에서 새 10마리가 비행합니다.
`main.py`로 소년과 새를 함께 실행합니다. `bird_main.py`도 같은 화면을 실행합니다.

## 실행

Python과 pico2d가 필요합니다. 저장소 루트에서 실행합니다.

```powershell
python -m pip install pico2d
python -m pip install transitions
python main.py
```

프로젝트 가상환경을 사용한다면:

```powershell
.venv/Scripts/python.exe main.py
```

좌우 방향키로 소년을 달리게 하고, Space로 공을 발사합니다.
Escape 또는 창 닫기로 종료합니다. 실행 경로와 관계없이 리소스를 찾습니다.

## 구현 논리

- 원본은 918×506 픽셀, 5열·3행이고 유효 프레임은 14개입니다.
  왼쪽에서 오른쪽, 위에서 아래 순서로 읽고 마지막 빈 칸은 제외합니다.
- 셀 경계는 이미지 크기에 행과 열 비율을 곱해 정수화합니다.
  크기가 나누어떨어지지 않아도 나머지 픽셀을 포함하며 아래쪽 원점으로 변환합니다.
- `frame = (frame + 14 * dt) % 14`로 초당 14장을 재생합니다.
  실수 프레임을 유지하고 그릴 때만 정수화하여 작은 시간도 누적합니다.
- `x += direction * speed * dt`로 픽셀/초 단위 이동을 계산합니다.
  소년과 같은 `game_framework.frame_time`을 사용해 같은 시간 기준으로 갱신합니다.
- 표시 폭 절반을 경계 여백으로 사용해 새 전체를 화면 안에 유지합니다.
  초과 거리를 반사하고 왕복 구간의 나머지를 계산해 큰 시간 간격에도 대응합니다.
- 원본은 오른쪽을 봅니다. 왼쪽 비행 시 `clip_composite_draw`의 `h` 옵션으로
  좌우 반전합니다. 방향이 바뀌어도 날갯짓 프레임은 계속 이어집니다.
- 이미지 한 장을 10마리가 공유합니다. 새마다 높이, 속도, 방향, 프레임을
  따로 유지합니다. 소년은 y=90에서 달리고 새는 y=240~510의 위쪽 공간에 배치합니다.
  새 10마리를 기존 `game_world`에 등록해 소년·잔디와 함께 갱신하고 그립니다.

## 파일

| 파일 | 역할 |
| --- | --- |
| `bird.py` | 스프라이트 좌표와 새의 이동 및 그리기 |
| `bird_main.py` | 10마리 생성 및 기존 화면으로 실행 연결 |

## 검증

```powershell
python -m unittest discover -s . -p test_bird.py
```

프레임 좌표, 시간 분할에 따른 결과 일치, 양쪽 경계 반사,
큰 시간 간격, 새 10마리 생성 및 방향별 반전을 검증합니다.

## 제출 확인

화면에서 새 10마리가 날갯짓하며 양쪽 경계에서 돌아서는지 확인합니다.
마지막 빈 칸은 재생하지 않으며, 날갯짓 한 주기는 1초입니다.
이번 과제는 기능별 15개 커밋으로 구성하고 마지막 커밋 로그에 구현 논리를 기록했습니다.
